## 🛠️ איך לערוך נתונים?

### אפשרות 1: עריכה ישירה של קובץ JSON (מומלץ למתקדמים)

1. פתחי את `App_Data/eurovision-data.json` ב-Visual Studio
2. הקובץ הוא מערך JSON - כל רשומה נראית כך:

```json
{
  "Year": 1978,
  "Artist": "יזהר כהן והאלפבית",
  "ArtistEnglish": "Izhar Cohen & Alphabeta",
  "Song": "א-בה-ני-בי",
  "SongEnglish": "A-Ba-Ni-Bi",
  "Rank": 1,
  "Sound": "פופ-דיסקו קצבי עם הברות עבריות שהפכו לאייקוניות בעולם",
  "Fashion": "חולצות צבעוניות ומכנסיים מתרחבים - סגנון דיסקו קלאסי",
  "Language": "עברית - שיר משחק ילדים שובב שכבש את אירופה",
  "Choreography": "תנועות קבוצתיות פשוטות ושמחות",
  "Tags": ["Winner", "Disco", "Iconic", "Aftershock"],
  "ImageUrl": ""
}
```

3. עדכני שדות כרצונך
4. שמרי את הקובץ
5. רענני את האתר - השינויים יופיעו מיד!

### אפשרות 2: דרך עמוד ניהול הנתונים

1. הריצי את האתר
2. נווטי ל-`data-manager.aspx`
3. תראי טבלה עם כל הנתונים:
   - **חיפוש**: הקלידי בתיבת החיפוש לסינון
   - **סטטיסטיקות**: מספר ניצחונות, מקומות 2-3, וכו'
   - **ייצוא**: כפתור "ייצוא ל-Excel" ליצירת קובץ CSV

## 🏷️ מערכת התגיות (Tags)

התגיות עוזרות לסנן ולקטלג את השירים. הנה התגיות הנפוצות:

### תגיות הצלחה:
- `Winner` - ניצחון (מקום 1)

- `Top5` - מקום 4-5

- `LGBTQ` - ייצוג LGBTQ

- `Peace` - מסר שלום

### תגיות עונתיות:
- `70s`, `80s`, `90s`, `2000s`, `2010s`, `2020s`

## ⚙️ טיפול בבעיות

### הנתונים לא מופיעים?

1. בדקי שהקובץ `App_Data/eurovision-data.json` קיים
2. בדקי שהקובץ הוא JSON תקין (אפשר להשתמש ב-[jsonlint.com](https://jsonlint.com))
3. בדקי שאין שגיאות בקובץ (פסיקים חסרים, סוגריים לא סגורים)

### שגיאת JSON?

פורמט JSON רגיש מאוד:
- ✅ כל מחרוזת עם גרשיים כפולים `"כך"`
- ✅ פסיק `,` בין אובייקטים (אבל לא אחרי האחרון!)
- ✅ סוגריים מסולסלים `{}` לאובייקט
- ✅ סוגריים מרובעים `[]` למערך

### האתר לא עובד ב-macOS?

ASP.NET Web Forms זה טכנולוגיה של Windows בלבד. כדי לבדוק:
1. השתמשי ב-Windows עם Visual Studio
2. או השתמשי בגרסת ה-demo: `timeline-demo.html`
