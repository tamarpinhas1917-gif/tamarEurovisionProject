# Eurovision Images Folder

## 📁 Image Naming Convention

Save all Eurovision performance images in this folder using the **year as the filename**.

### Naming Format:
```
YYYY.jpg    (or .png, .jpeg)
```

### Examples:
- `1973.jpg` - Ilanit "Ey Sham"
- `1978.jpg` - Izhar Cohen "A-Ba-Ni-Bi" (Winner)
- `1979.jpg` - Gali Atari "Hallelujah" (Winner)
- `1983.jpg` - Ofra Haza "Chai"
- `1998.jpg` - Dana International "Diva" (Winner)
- `2018.jpg` - Netta "Toy" (Winner)
- `2023.jpg` - Noa Kirel "Unicorn"
- `2024.jpg` - Eden Golan "Hurricane"

### Supported Formats:
- ✅ `.jpg` or `.jpeg` (recommended - smaller file size)
- ✅ `.png` (if you need transparency)
- ✅ `.webp` (modern format, best quality/size ratio)

### Recommended Image Size:
- **Width:** 800-1200px (will be resized automatically by CSS)
- **Aspect Ratio:** 16:9 or 4:3 (landscape)
- **File Size:** Under 500KB per image (compress if needed)
