## BEFORE CLASS - At Home ⏰ (10 minutes)

### 1. Prepare External Drive
- [ ] Connect USB/external drive to Mac

- [ ] Eject drive safely

### 2. Verify What's on Drive

## IN CLASS - At Computer ⏰ (5-10 minutes)

### 3. Copy to Class Computer
- [ ] Plug drive into Windows computer
- [ ] Open File Explorer (Windows + E)
- [ ] Find drive (usually D: or E:)
- [ ] Copy `tamarProject` folder
- [ ] Paste to `C:\Users\[YourName]\Documents\`
- [ ] Wait for copy to finish
- [ ] Eject drive

### 4. Open in Visual Studio
- [ ] Go to Documents → tamarProject
- [ ] Double-click `TamarFinalProject.sln`
- [ ] Visual Studio opens (wait 30 sec)
- [ ] See "Solution Explorer" on right side

### 5. Set Startup Page
- [ ] In Solution Explorer, expand `tamarProject`
- [ ] Find `homePage.aspx`
- [ ] RIGHT-CLICK on `homePage.aspx`
- [ ] Click "Set As Start Page"
- [ ] File should now have green arrow ▶️

### 6. Build the Project
- [ ] Menu: Build → Clean Solution
- [ ] Wait for "Clean succeeded"
- [ ] Menu: Build → Rebuild Solution
- [ ] Bottom shows "0 errors" ✅

### 7. RUN! 🚀
- [ ] Press F5 or click green Start button
- [ ] Browser opens automatically
- [ ] Home page displays
- [ ] Hebrew text readable (not ×©™ symbols)

## IF SOMETHING GOES WRONG 🐛

### Problem: Hebrew shows as ×©™
**Fix:** Build → Rebuild Solution, then F5

### Problem: "Not valid startup item"
**Fix:** Right-click homePage.aspx → Set As Start Page

### Problem: Images missing
**Fix:** Check images/eurovision folder exists (48 files)

### Problem: Won't build
**Fix:** Build → Clean Solution, then Rebuild

### Problem: Can't find file
**Fix:** Make sure you opened the .sln file (not .aspx)
